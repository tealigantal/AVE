# AI Vlog Co-Editor

AVE is a local, conversational AI Vlog editor that turns real media into traceable, verifiable films under Project Host authority.

## Install and verify

```text
pnpm install --frozen-lockfile
pnpm run docs:sync
pnpm run docs:check
pnpm run check
pnpm run acceptance:final:synthetic
```
