# AI Vlog Co-Editor

由 Project Host 控制的本地 AI Vlog 编译系统。当前为 WO-001 工程基座，尚未提供可用的桌面剪辑界面。

## 环境

- Node.js 20+
- npm（当前已验证）
- pnpm（目标工具，当前未验证）

## 安装与检查

```text
npm install
npm run check
```
