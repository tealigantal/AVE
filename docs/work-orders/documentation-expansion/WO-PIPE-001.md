# WO-PIPE-001 Intelligence-to-Timeline integration

- Goal: connect approved Story/Style decisions to Edit Intent, Edit IR and CommitPlan.
- Motivation: turn intelligence into safe editable output.
- Input: approved artifacts and existing contracts, Timeline Core, RenderGraph and QC.
- Output: provenance links, resolver decisions, simulations, commits and blockers.
- Dependencies: WO-INT-003, existing editing-execution-v1 capability completion.
- Non-goals: bypassing Host, adding an unconstrained agent or claiming unsupported execution.
- Acceptance: Preview/Master share semantic identity; failures leave Timeline unchanged; provenance survives reopen and undo/redo.
