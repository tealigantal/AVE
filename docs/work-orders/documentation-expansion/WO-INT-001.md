- Goal: define versioned Skill, evidence, conflict, evaluation and provenance contracts.
- Motivation: make creative knowledge reusable without executable authority.
- Input: Creative Skill Library and Preset/Skill interface.
- Output: schemas, generated bindings, validator tests and migration policy.
- Dependencies: WO-DOC-001.
- Non-goals: arbitrary model tools, marketplace execution, direct Timeline mutation.
- Acceptance: invalid evidence/conflicts/version pins fail closed; accepted output maps only to typed downstream artifacts.
