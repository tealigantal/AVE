# WO-INT-003 Story and editing reasoning

- Goal: implement Story Candidates, beat evidence and Decision Records through Edit Intent.
- Motivation: every timeline change must be explainable and traceable.
- Input: approved contract, material evidence, skills, duration and style/trend advice.
- Output: versioned candidates, approved Story Plan, typed Edit Intent and local patch proposals.
- Dependencies: WO-INT-001, WO-INT-002, existing evidence/story Host boundaries.
- Non-goals: direct commands, autonomous commit or unexplained full re-cut.
- Acceptance: each decision has evidence, reason, confidence, alternative and affected range; Host remains sole committer.
