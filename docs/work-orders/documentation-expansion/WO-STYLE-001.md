# WO-STYLE-001 Reference style extraction

- Goal: extract a compatible Style Profile from a user-approved reference.
- Motivation: translate “I want this style” into adaptable principles rather than copying.
- Input: reference media, creator contract, platform and material evidence.
- Output: paced, camera, subtitle, color, music and narrative dimensions with confidence and rights.
- Dependencies: WO-RESEARCH-001.
- Non-goals: protected-shot or music copying; silent creator-identity changes.
- Acceptance: compatibility report labels compatible, adaptable and conflicting dimensions and retains evidence.
