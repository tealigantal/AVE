# Workspace Design

## 唯一设计依据与权威

P4正式工作台按 `demos/p4-workbench/index.html`、`demo.js`、`demo.css` 的页面、层级、导航、控件位置和交互实现。固定摘要与执行次序见 [DOC-007](../plans/2026-10-03-reliable-workbench-real-acceptance.md)，逐操作范围见 [P4工作包](../program/creative-assistant-stage3/work-packages/WP-S3-RELIABLE-UX-001.md)。本文只定义现行行为，不记录构建成功或能力状态；状态查programme/current，历史事实查Evidence。

先完成全部真实内部功能，再逐页重做UI。不保留旧HTML/侧栏/主题作为平行依据。demo固定数据、回复、模拟状态和CSS效果不进入产品；Project Host仍是状态权威，普通操作使用受限API与真实回执。

## 页面与对象

提供创作、素材、精修轨道、版本历史、问题与恢复、作品管理、回收站、帮助、导出九个页面；可隐藏导航，页面切换保留项目、当前观看版、编辑版、未发输入、选择和焦点。作品/帮助不能因为现有内部route没有独立枚举而被省略。

素材页负责导入、分类、搜索、视图/尺寸调整与真实浏览；精修资源栏负责时间线写入。未连接外部目录显示空或不可用，不填造库存。图片使用正确方向的真实缩略图，视频使用真实画面；声音有实际试听与类型，不以文件名或假波形代替。

精修页面复现demo资源栏、中央预览、属性栏与多轨时间线；各面板独立调节、折叠与恢复。主视频和PiP相邻；可选轨按实际内容及显式新建状态显示。宽窄窗口不靠横向溢出隐藏操作，正文和诊断保持可读。帮助与实际手势/快捷键一致。

## 时间、拖放与连续编辑

所有轨道、标尺、播放头、吸附共用项目帧率与RationalTime；音频源范围按真实采样边界校验。屏幕秒数只是显示，不回写为权威浮点时间。

- 新主视频/图片按前后剪辑点插入完整片段并顺延；已有主视频按前后重排，保留各段时长。普通拖放不拆片、不暗中修剪。边缘手柄才修剪，显式分割才拆片。
- PiP、音频、字幕/文字均有demo对应的选中、移动、修边、分割、删除与撤销行为。主视频/PiP同轨禁止重叠；不同对象只能放匹配轨。拖动显示源占位和合法目标，取消恢复；松开才通过Host一次原子提交。
- 拖动期间临时轨不写项目；有效落下原子建轨并插入。显式新增空轨允许接下一次放置；删轨包含其内容且可撤销，主视频不可删除，锁/保护范围仍生效。移走/删除最后对象时清理对应可选轨，与该操作原子提交。
- 轨道范围随内容和播放头扩展；内容外空白可定位、落片，不夹到当前最后片段。播放器seek只能在其真实可播放范围内，不因此限制编辑时间轴。
- 标尺只画可视区；滚轮以指针时间为锚缩放、Shift竖滚、Alt横移；吸附规则对照固定demo，排除自身边界，支持起止边吸附和开关，吸附不改变时长。
- 观看旧预览不阻断对当前Host Timeline的合法连续编辑。明确显示观看版/编辑版；编辑不假装旧画面已更新，不抢播放。旧版本提交仍拒绝，撤销/重做按钮与快捷键使用同一可用规则。

## 字幕、效果与转场

字幕/文字资源可拖入对应轨并编辑时间。预览字幕可直接编辑；Enter或失焦提交一次，Escape恢复已保存值。字体、字号、颜色、粗细由真实Timeline和Worker输出，未知/缺失字体不假成功；保留已有源范围、图片构图、音频gain/fade/ducking/mute/solo等正式能力入口。

灰度、黑白、模糊只作用于明确视频对象及范围，重复应用替换或安全拒绝，不静默叠加；支持清除/删除及撤销。当前无强度参数的效果不造强度控件。Preview/Master都实际渲染，CSS不作能力证明。

交叉叠化绑定相邻主视频剪辑点，校验素材余量/overlap；再次放置替换该点转场，可选择/Delete删除/撤销恢复。转场不建独立轨；片段边缘淡入淡出是另一语义，不包装成两输入转场。未注册效果与明确未连接目录不启用。

## 共享对话与批注

创作与精修共用一个普通输入节点、一段消息流和浮动对话入口，页面切换不销毁/搬移其输入状态。气泡可拖动，位置按项目保存。选择整部作品或当前对象范围必须清楚，当前对象失效不能暗中改为全局。

批注正文在独立窗口编写，锚点卡与正文分开；预览批注包含实际解码画面内的归一化位置及精确帧，排除留黑区域；时间线批注绑定项目、request/draft、Timeline版本和轨道/片段/时间。空间点仅是用户上下文，不是渲染命令。

待发批注可添加、编辑、移除、清空；整体要求和整组批注一次发送为一条组合消息，结构化字段分开。Host校验授权、对象和版本，保存消息并建立可恢复任务关系；模型读取有界上下文，经当前规划和Command/Commit链产生结果，正文不成为系统指令。

发送失败保留正文与队列；发送成功清待发输入并展示真实处理状态；仅持久化成功不能称“已解决”。未解决或失败批注保持可查、可重试；实际处理完成后撤下活动标记。历史正文与原锚点保留，默认不常驻活动标记层，点击历史时可临时定位。剪切/移动后只接受唯一映射，多义/删除时显示unresolved，不按同名片段猜位置。

上述处理闭环是P4待实现要求，不由既有持久化子包自动满足。当前协议新增写入只使用唯一当前版本；历史事件不重写，精确重放不产生第二次任务。

## 新增效果的共同交互要求（目标，待实施验证）

所有新增效果与原有精修页面共用轨道、选择、属性栏和独立批注窗口，不引入第二个竞品编辑器作为必经入口。图形和字幕允许定位到有稳定身份的元素/词范围，音频和画面效果允许定位到对应实例及时间范围；转场继续依附剪辑点，进入精修不等于强制为每种效果建立独立轨。预览空间点必须结合命中对象与观看版本，重叠对象显式选择，不能猜测目标。

批注保留逐条正文、原锚点和来源版本；可同时积累多个区段，一次发送整体要求和整组批注。每条要求显示待处理、执行中、冲突/失败或经结果验证的完成情况，并能查看关联的新版本与实际变更。整批渲染成功不自动解决所有批注；失败不清空未完成项，重试不得重复施加已完成操作。目标被删除或映射多义时保留正文并要求重新定位，不能扩大成全片修改。

手动移动、修边、分割、复制和变速时，对象内容时间与入退场动画时间的处理规则必须明确；不会因裁剪自动重播完整动画，也不会悄悄删除关键帧。用户选择固定成片时间、跟随片段或跟随词句的锚定方式后，后续 AI 修改须保留该选择和手动参数。所有交互经同一 Host 版本提交与冲突检查。具体合同与验收覆盖见 [DOC-015](../plans/2026-11-11-cloud-editing-benchmark.md#doc-015hypit-模块核对与完整交付实施方案)；此要求不宣称现有协议已经支持元素锚点或逐条结果。

## 连续交互与版本

进入/返回项目、切页与面板时保留输入与选择；打开面板合理移入焦点，关闭回原触发控件；页面记住仍连接、可见、可用的最后焦点。对象失效时丢弃旧引用，异步结果不抢焦点。输入框/中文IME期间不触发时间线删除/分割快捷键。

制作中仍可输入和提交获准修订；新版本只提示就绪，用户决定观看/采用。比较按asset identity、source PTS和lineage对齐；没有对应内容明确显示，不按影片百分比伪同步。相同合法已解码媒体复用播放器、位置和状态；身份改变、解码错误或失效仍走真实校验和加载。

初次恢复项目/UI时显示恢复状态，避免旧读取覆盖新输入；普通刷新或后台制作事件不重新禁用全部输入。跨窗口项目切换拒绝过期请求并同步权威状态，不把stale控制流伪装成普通业务失败，也不放宽身份检查。

## 失败与恢复

操作失败以普通中文顶部红色提示约两秒淡出；持久问题保留根因、对象、影响、提交状态和可执行下一步。关闭提示或无关成功不删除问题；至少30秒后仍可查。失败不可用默认值、空列表或假进度掩盖。

保存失败明确哪些未保存并保留重试入口；损坏项目阻断相关写入。模型/渲染取消保存合法已完成成果，晚到结果不提交；重开只恢复实际已保存请求、版本、来源与回执，失联素材不按同名自动匹配。档案查询重开后由Host重新校验授权/例外/遗忘，不能由表单猜测旧授权或使用陈旧快照。

## 素材、许可与导出

导入允许当前作品内编辑，不自动授权云处理、第三方素材获取/再许可或公开分享。音频库浏览读目录元数据，试听由Host下载校验；已选资源保留项目原件及来源/许可，试听缓存清理不删除已用素材。新请求明确启用库，历史请求不自动扩大权限。

导出锁定项目/草稿/Timeline/渲染与QC身份，质量选项只列实际可支持值；切项目使旧回调失效。Browser保留成片、音频来源JSON、署名文本三个独立下载入口；不能观测系统保存则只显示“下载已开始”。Electron按实际保存回执报告，失败不覆盖旧合法文件。

## 作品与回收站

作品列表是Main导航索引，Renderer只拿不透明引用、名称与时间；再次打开由Host核验身份，不扫描磁盘或填造封面。回收站逐项/全部恢复、永久删除与取消均走真实接口。永久删除显式确认，校验Host身份、锁、专属路径与外来文件；保留外部原片、独立导出、共享档案及其他作品。中断保留可恢复状态，不能仅隐藏卡片声称删除成功。

## 验证边界

Agent完成自动化、失败注入、当前构建的真实交互、媒体解码与机器记录；人工审核、审美/听感反馈可选，不阻塞完成，不要求重复授权。缩放125%/150%、窄窗口、键盘/IME、减少动态、连续输入/编辑和恢复均须覆盖。HTTP、截图、界面字符串和专项通过不代替真实完整旅程。具体OP、WIN与完成记录只引用工作包和DOC-007，不在本文复制状态。

## 2026-10-15 current Browser entry clarification

For the current P4 user journey, the running application entry is the Compose Browser at `http://127.0.0.1:6080/`. It shares Renderer modules with Electron, but uses the web Host and `/api/invoke` instead of Electron preload IPC. A failed Electron journey is not evidence that the deployed Browser entry fails; it remains a historical signal about the shared Renderer path. P4's WIN-09 and WIN-10 automated interaction receipts must exercise the current Docker Browser build. HTTP availability and container health alone do not establish those interactions. See DOC-012 for the deployment/source-routing evidence.

The suggestion to move detailed creation-time permissions to global settings is an open product decision. This design does not declare that change approved or implemented.
Current-project recycle uses the unique recent-entry reference whose project_id matches the open project. The Renderer must not send the project UUID as a navigation ID. Summaries expose these two opaque identities and display metadata only, never the project path. If the mapping is missing or ambiguous, the current-card action stays unavailable and the recent-entry actions remain explicit.
