# WP-CA-UX-001 Representative Stage 2 user-journey evaluation

## Goal

Evaluate the accepted Stage 2 desktop workspace as one complete creator
journey over authorized real media: inspect same-version intent and evidence,
compare alternatives, reject safely, approve exact effects, review the encoded
first cut, request and decide one scoped revision, recover through undo/redo
and reopen, and judge the final QC-passing delivery.

## Evaluation boundary

This package creates no application capability. It consumes the exact Product,
first-cut and feedback identities already accepted by their owning packages.
The evaluator records clarity, controllability, visible effect, recovery and
failure-closure findings. A defect or material ambiguity blocks evaluation and
is routed to a separate repair package; it is never silently fixed inside this
docs-only scope.

## Acceptance

`ACC-CA-UX-001` requires a representative, user-visible journey record tied to
authorized real media and exact project/version/Preview/Master/QC identities.
The record must cover at least two candidates, safe rejection, exact approval,
the accepted first cut, one scoped revision, undo/redo/reopen recovery and the
reviewer's explicit outcome.
