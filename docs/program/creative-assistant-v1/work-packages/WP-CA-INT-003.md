# WP-CA-INT-003 Comparable Story reasoning and semantic Edit Intent

This is the governed promotion of candidate `WO-INT-003`. Current Contracts,
source, tests and Evidence outrank the candidate document if they conflict.

## Goal

Persist at least two reproducible evidence-bound Direction and Story candidates,
record exact selection/rejection/approval decisions, approve one frozen Story
payload and produce a command-free semantic Edit Intent candidate.

## Authority and compatibility

Project Host owns all registration and exact-version approval. Candidate
generation consumes a bounded exact Creative Context: current approved Creative
Contract, current sufficient Material Evidence Pack, exact Skill Evaluations,
Duration Blueprint/Feasibility, optional advisory refs, current Timeline version
and capability snapshot. Existing editorial v1 Story records remain readable;
v2 Contracts and persistence are additive.

Direction Cards, Story candidates, Decision Records and semantic Edit Intents
are immutable content-addressed project artifacts. Model output is candidate
input only and must pass Contract Runtime plus deterministic hard gates. Semantic
operations are registered data, use RationalTime and contain no Timeline
Commands, RenderGraph nodes, backend strings or execution authority.

## Acceptance

`ACC-CA-INT-003-STORY` proves two comparable evidence-complete candidates,
deterministic ranking, alternatives, exact selection/approval/rejection,
Decision Records, idempotency, migration and reopen.

`ACC-CA-INT-003-INTENT` proves an approved exact Story can produce a persisted
command-free semantic Edit Intent bound to the current Timeline/capability
snapshot, while stale refs, protected targets, unsupported semantics and forged
execution fields fail closed with zero Timeline mutation.

Model quality, direct Command/Commit, execution adaptation, rendering, Style or
Trend ingestion, feedback recut and autonomous approval are non-goals.
