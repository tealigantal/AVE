# WP-S3-RELIABLE-PREVIEW-001 — 浏览播放与严格采样分离

本文件属programme工作包规范层，由生成WORK和DOCUMENT_INDEX导航；现有DOC-007记录整体顺序，本规范负责P2具体执行边界，不另建状态源。依赖P1完成协议；未启动时不授权运行修改。依据DOC-007 P2和ADR-0041，不提升editing-v1高级剪辑范围。

当前`ProjectHostSession.readMediaPreview`混合缩略图、波形与最多15秒严格音频采样，`measureCreationAudioResource`复用其严格结果。Renderer素材侧栏只显示派生图片/音频，没有完整视频浏览。P2建立独立浏览准备链，同步所有严格调用方，严禁为播放放宽`MEDIA_SAMPLE_AUDIO_GAP`或将浏览音频当精确测量收据。

## 交付与不变量

- Worker准备真实图片、完整视频和独立音频的浏览器兼容派生物；Host校验来源摘要、派生文件身份、转换策略与工具身份。原片不修改，Master仍使用Original。
- Host持有派生物及不透明引用，Browser和Electron只通过受限入口访问。引用绑定作品、会话和来源；Range、HEAD、越界、撤销、跨会话与来源替换必须明确验证。Renderer不获得原片路径。
- 点击素材进入中央浏览，具备准备/失败/重试状态、播放/暂停/跳转/音量/全屏；图片支持缩放与恢复。返回作品保留原观看版本及播放状态。素材浏览与作品预览是不同身份。
- 快速切换、关闭侧栏或换作品取消旧请求，停止旧声音、释放播放器/派生句柄；过期结果不能覆盖新选择。音频和波形失败单独报告，不制造无音轨或完成假象。
- 浏览坐标不能直接形成精修边界；Host提供有证据的源时间映射或明确阻断。VFR、非零起点、edit list、编码延迟及真实内部间隙分别验证，严格采样仍保留失败根因。
- 复用当前SQLite格式与Host引用保护，清理只处理可核对的无引用派生临时物；保留全部原片、历史作品与首次失败Evidence。
