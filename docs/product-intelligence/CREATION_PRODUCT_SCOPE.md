## 产品结果和完整流程

AVE 是本机剪辑应用。用户创建或打开真实项目、导入素材，表达目标或直接开始制作。无需先读素材报告、填偏好问卷、选 Direction/Story 或逐层批准剪辑计划。一次请求在明确素材、目标、模型部署、隐私和保护范围内授权可撤回草稿制作。内部可以比较候选，默认交付一版有判断力的完整主初稿；“再试一种”才打开另一方向，不把内部比较变为入口门槛。

初稿整体考虑选材、叙事、节奏、现场声音、音乐、字幕和必要画面处理。没有传统结尾镜头可以用真实动作/对白/场景收尾；不能虚构事件、对白、反应。真实素材无法支持硬目标时说明具体缺口，只询问影响可执行性的选择。

制作中输入始终可用；新话只替换冲突要求，保留其余意图和不受影响成果。用户看到“已收到”“正在调整”“已进入当前可观看版本”的真实区别。看着作品说“开头无聊”“太像宣传片”，AVE 将感受转为素材适用的剪法，直接制作可撤回新草稿。多镜头、声音、字幕联动属于同一请求；满意/锁定部分稳定。手动精修与语言修改共享当前作品状态。旧版、撤销、比较、再试方向及组合用户选中的版本片段都在同一项目版本链内。

用户可一次开启指定项目集合/参考和数据范围内的学习。原话、选择、修改差异、手动操作和真实反馈形成可纠正经验，进入未参与学习的新项目。当前明确要求优先；支持这次例外、长期纠正、项目排除、遗忘。初次无档案仍可直接制作。导出前检查事实、衔接、字幕、重复、硬要求和技术质量；审美和听感反馈可由用户补充，自动执行与验证不等待人工签字；导出与对外发布分开。

非目标：云同步、Marketplace、基础模型自训练、自动发布、开源许可证/发布、任意模型支持和完全离线承诺；也不要求所有高级剪辑家族先完成。不能借“当前不支持”推迟本阶段必要视听语义。

## 范围与验证映射

此表定义产品要求；已实现程度由 programme 矩阵和当前产物判定，不沿用最初的“仅固定 Story”“尚无档案”等起始描述。

| 产品行为 | 必须保持的结果 | 验证场景 |
| --- | --- | --- |
| 无档案直接制作 | 请求内完成非等长选材、叙事和视听主计划，交付真实主初稿 | C1：素材、请求、模型账本、首稿和输出绑定 |
| 制作中插话/取消 | 请求修订与依赖失效；过期结果不覆盖当前，取消释放任务 | C2：事件序列、提交代次与失败无错误提交 |
| 感受转为剪法 | 原话、原则与素材事实绑定；改变叙事/视角，不伪造对白和事件 | C3：原话到多镜头/声/字幕的真实版本差异 |
| 节奏、留白、满意部分 | move/trim/ripple、句子和动作边界、保护范围共同成立 | C4：编辑前后时间及解码声画对照 |
| 必要编辑与画面处理 | 替换/重排/删除/插入、关联音频、构图及注册效果实际渲染 | C5：逐对象操作与 Preview/Master 同语义对照 |
| 主动学习与情境复用 | 授权内真实反馈进入未参与学习的新项目，支持例外/纠正/排除/遗忘 | C6：留出项目、记忆来源、作品差异和删除反例 |
| 版本、手动精修和 demo 界面 | 共享当前作品状态，草稿/采用/播放指针清晰；重开与撤销可恢复 | C7：正式界面操作、版本血缘和重开状态 |
| 声音、字幕、质量与导出 | 现场声/音乐独立范围、gain/fade/ducking、字幕内容/时序、真实 QC | C8：实际解码画面、音频输出、Master 与署名文件 |
| 用量、权限和失败 | 实际调用记录、授权内执行、根因透明、无隐藏降级或伪成功 | C9：拒绝/取消/服务错误后的状态与恢复证据 |

C1–C9 的详细定义复用 [Creative Quality Benchmark](CREATIVE_QUALITY_BENCHMARK.md)。历史 P4 的界面操作记录不作为当前执行入口。

## 当前执行顺序与旧模块处理

按 DOC-007 的 L0–L7 执行：补回归入口 → 连续精修与时间域 → 全对象手势 → 字幕/特效/转场 → 批注和共享对话真实处理 → 项目/素材/版本/导出 → demo 视觉统一 → 全链自动验证。一次完成一个可复验单元，记录实际结果后继续下一个，不等待人工审核。

Stage3 必需编辑子集由实际调用链决定；`WP-XFORM-002` 不是整个 Stage3 的前置。仅允许当前合同的新写/执行入口，物理移除替代后的旧入口及其调用方；历史项目和历史收据所需的只读解析/回放保留，不能用删除数据制造“清洁”。精确清理项目见 DOC-007。

当前请求范围内不逐项批准 Direction、Story、内部计划或 exact effect。数据范围、隐私和损坏状态不能用默认值补齐。模型响应违反合同则保留根因并失败，不裁参、补引用、切换固定模板或隐藏换模型。

## 混合素材资源包和基础精修

JPEG/PNG/WebP 的静态身份、展示时长与独立音频沿既有观察、规划、Command/Commit 和双目标渲染路径处理。视频保留场景与帧验证，图片和纯音频不伪造视频扫描。图片使用真实解码方向和透明通道；独立声音区分 narration、music、sfx；对白 ducking 只作用于音乐；不同输出尺寸使用每段显式注册构图。

免费音频库使用固定版本目录，按需验证原站下载并只保留已选素材。新请求可显式授权自动选曲：第一轮读取不超过12个元数据候选并指定曲目，Host 仅获取选中资源并保存真实采样收据，第二轮只安排这些实测来源。现有配乐及手动来源通过实际内容绑定的历史收据进入后续修改；保护、音量和真实源范围继续校验。无配乐要求优先，失败不换曲或交付缺失配乐的成功状态。选曲理由、少量可试听替代及来源/许可在工作台展示，实际 Master 导出附音频清单与署名。范围不扩展为整个专业混音家族。


基础精修通过 `PrecisionEditV1` 的 Host 适配，支持显式源范围/展示时长、关联分割/复制、作品级波纹删除、图片静态变换与构图、音频选段/增益/淡化/重复/静音/独听/关联、字幕内容/时序及基本排版。采用真实帧/采样网格与作品 RationalTime，无隐式时间取整。每次操作提交一个原子版本，历史恢复支持撤销和重做。父版本画布、手动路由/关联与作者字幕可进入后续语言修改；不可表示的高级动画、跟踪或变速裁切明确拒绝。该扩展仅覆盖列出的实际子集，真实生产模型浏览器/Electron 旅程由 DOC-007 的 P5 自动验证；人工体验反馈可选。
