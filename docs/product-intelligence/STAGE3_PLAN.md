## 产品结果和完整流程

AVE 是本机剪辑应用。用户创建或打开真实项目、导入素材，表达目标或直接开始制作。无需先读素材报告、填偏好问卷、选 Direction/Story 或逐层批准剪辑计划。一次请求在明确素材、目标、模型部署、隐私和保护范围内授权可撤回草稿制作。内部可以比较候选，默认交付一版有判断力的完整主初稿；“再试一种”才打开另一方向，不把内部比较变为入口门槛。

初稿整体考虑选材、叙事、节奏、现场声音、音乐、字幕和必要画面处理。没有传统结尾镜头可以用真实动作/对白/场景收尾；不能虚构事件、对白、反应。真实素材无法支持硬目标时说明具体缺口，只询问影响可执行性的选择。

制作中输入始终可用；新话只替换冲突要求，保留其余意图和不受影响成果。用户看到“已收到”“正在调整”“已进入当前可观看版本”的真实区别。看着作品说“开头无聊”“太像宣传片”，AVE 将感受转为素材适用的剪法，直接制作可撤回新草稿。多镜头、声音、字幕联动属于同一请求；满意/锁定部分稳定。手动精修与语言修改共享当前作品状态。旧版、撤销、比较、再试方向及组合用户选中的版本片段都在同一项目版本链内。

用户可一次开启指定项目集合/参考和数据范围内的学习。原话、选择、修改差异、手动操作和真实反馈形成可纠正经验，进入未参与学习的新项目。当前明确要求优先；支持这次例外、长期纠正、项目排除、遗忘。初次无档案仍可直接制作。导出前检查事实、衔接、字幕、重复、硬要求和技术质量；审美接受来自真实用户，导出与对外发布分开。

非目标：云同步、Marketplace、基础模型自训练、自动发布、开源许可证/发布、任意模型支持和完全离线承诺；也不要求所有高级剪辑家族先完成。不能借“当前不支持”推迟本阶段必要视听语义。

## 开发顺序与第一条联调

候选包及穷尽允许范围见 [Stage3 Work Orders](../work-orders/stage3/README.md)。先 S3-01 统一请求授权、输入修订、草稿/采用/播放版本和共享对象身份；它不是要求一个场景零缺陷的长期前置。共同字段定稿后，S3-02 反馈转化、S3-03 档案、S3-04 生成编辑、S3-05 工作台可以分别准备/验证纯逻辑及接口适配，按单 active package 规则依次登记共享写入。跨工作树并行也不授权同时修改共享 Host/Schema；共同合同由 S3-01 主持，后续每包同步其消费方，合入前核对基线。

第一条完整路径：获准日常历史/参考 → 未参与学习的新素材主初稿 → 制作中“不要煽情” → 看片多镜头声字幕调整 → 纠正“夕阳留着，只删那句话” → 更新获准假设 → 第三个新项目复用，并跑本次例外和遗忘。先在 S3-02/03/04/05 的第一批可执行接缝联合运行 C1/C2/C3/C6；S3-06 从此收集真实输入/对照，不等其他模块完美才介入，也不把日常案例当成阶段上限。

Stage3 必需编辑子集归 S3-04；WP-XFORM-002 不是 Stage3 同义词或一刀切前置。依赖仅凭对应已验证的执行子集，不凭目录、Schema 或整个工具家族名。
