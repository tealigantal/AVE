# Creative Metrics

## Metric families

| Family | Example measures | Interpretation guardrail |
| --- | --- | --- |
| Story | evidence coverage, contradiction count, causal coherence, beat completeness | high drama is not universal quality |
| Edit | unexplained omission, shot/beat fit, continuity defects, pacing deviation, intelligibility | effect count is not edit quality |
| Collaboration | first-useful-cut time, revisions, patch locality, undo/recovery events | fewer revisions can indicate disengagement; pair with satisfaction |
| Trust | citation precision, confidence calibration, blocker recall, explanation helpfulness | verbosity is not transparency |
| Satisfaction | keep/reject rate, intent fit, perceived control, publish willingness | publication is contextual, not blanket approval |
| Technical | contract validity, atomic commit, semantic parity, render/QC success | technical pass cannot establish creative acceptance |

## Decision-level record

Each evaluated creative decision pins the proposed change, reason, evidence,
confidence, alternative, user response, later modification, and outcome scope.
Metrics aggregate only compatible records and retain denominators and missing
data.

## Calibration

Confidence is evaluated against observed correctness or reviewer agreement, not
against model self-consistency. Evaluation separates evidence sufficiency,
creative preference, execution support, and user consent.

## Anti-gaming

- never optimize engagement proxies against explicit creator intent;
- never improve acceptance rate by hiding alternatives or blockers;
- never reduce revision count by making feedback difficult;
- never count silent fallback as successful capability;
- never average away failures for protected, minority, language, or difficult
  segments;
- never reuse private outcomes outside their consent scope.

## Reporting

Report distribution, segments, confidence intervals where appropriate, reviewer
agreement, qualitative failure themes, and representative counterexamples.
Keep current benchmark results in versioned Evidence, not in this policy file.
