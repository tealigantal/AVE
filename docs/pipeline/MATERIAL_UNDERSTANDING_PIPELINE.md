# Material Understanding Pipeline

Import establishes stable media identity and worker-produced probe facts.
Analysis then derives speech, shot, face/person, action, location, audio,
emotion and continuity observations with exact source/time references and
confidence. A sufficiency pass reports coverage and missing evidence for the
Creative Contract.

The output is an immutable, amendable Material Evidence Pack. Corrections append a new
version. Workers analyze; Project Host persists identities, provenance and
state. Originals, SQLite and model SDKs never cross the renderer boundary.

The target pack is a versioned reference snapshot over existing Evidence
objects, not a duplicate Evidence store; see
[`OBJECT_MODEL.md`](../intelligence/OBJECT_MODEL.md#materialevidencepack).

## Stage3 无强制素材报告的边界（目标）

素材理解为内部必需工作，用户不必逐项读报告/批准普通观察才得到第一版。Host 区分 probe/源引用等可验证事实、模型解释和用户明确纠正；在请求政策内登记经过来源/时间/覆盖验证的可用观察，记录真实 producer/validation basis，不伪造人工 reviewed。主观情绪/因果不因模型置信度变成事实；影响硬目标的歧义或证据不足才询问。S3-01/04 同步替换当前 Pack 对 approved evidence 的强制旧入口和相关权限/合同消费者，保留 immutable Original 与精确 PTS 身份。
