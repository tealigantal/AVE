# Tool Usability Registry

This registry is the operational boundary for tool usability tests. A `CAP-*` family can remain incomplete while one of its bounded tools is available: family status answers whether the full professional catalogue is complete; this registry answers what can be accepted and used now. A tool is usable only when its named test proves a committed change, encoded output, reopen persistence, and a failed input that leaves the Timeline unchanged or prevents publication.

Run the aggregate suite with `pnpm run acceptance:tool-usability`.

| Tool name | Status | Current bounded contract | Required executable evidence | Deliberately outside this tool |
| --- | --- | --- | --- | --- |
| PiP and position animation | available | Layered PiP with static placement and bounded X/Y animation. | `acceptance:advanced:tools:real` creates the committed Preview/Master review. | Full transform automation, anchor/original-size behavior. |
| Static Vertical Reframe | available | Fixed manual focal point; `crop_fill`, `contain`, or `blurred_background` to 9:16. | `basic-vlog-toolkit:test` verifies output geometry and mode-specific pixels; host test verifies commit/reopen and failed publication. | Subject detection, following, keyframed reframe, optical flow. |
| Directional slide, Zoom, Dissolve, Pixelize | available | Named transition effect must match its actual encoded visual behavior; Pixelize is never called Luma Wipe. | `acceptance:advanced:tools:real` plus explicit-overlap validation and invalid-transition failure closure. | True luma-matte semantics or unregistered transition types. |
| Clip Boundary Fade | available | Per-clip video fade to/from black and audio fade to/from silence. | `basic-vlog-toolkit:test` verifies pixels/amplitude and invalid-duration failures. | Two-input transition semantics. |
| Master Loudness | available | `-14 LUFS`, `-1 dBTP` default bounded master normalization. | `basic-vlog-toolkit:test` verifies LUFS, true peak, deterministic output, and no-audio behavior. | General mastering chain. |
| Dialogue/Music Ducking | available | One Dialogue/Narration sidechain and one Music bus, with bounded attenuation. | `basic-vlog-toolkit:test` proves attenuation, recovery, and that music remains measurable during dialogue; host test verifies commit/reopen. | Arbitrary buses, envelopes, pro mixing. |
| Constant Time Remap | available | Exact rational constant speed, freeze, and reverse with preserve-pitch audio. | `worker:render-correctness:test` verifies encoded hold/reverse frames and audio reverse. | Continuous speed ramp, optical flow, change-pitch. |
| Tracking Mosaic | available | Externally supplied or AI-produced tracking samples move a constant-size rectangular mosaic; a corrected sample changes the later trajectory. | `acceptance:advanced:tools:real` uses a non-linear trajectory ending in a corrected sample; `timeline-core:test` retains invalid-sample failure closure. | Built-in target detection, animated size, ellipse tracking. |
| Rectangle Alpha Mask | available | A rectangular alpha region exposes lower composition layers. | `acceptance:advanced:tools:real`, commit/reopen, and invalid-mask failure closure. | Person/subject segmentation or a semantic matte. |
| Text and timed graphics | available | Timed text, word-highlight captions, logo text, location text and CTA text. | `timeline:audio-caption:test` verifies the committed graph and encoded caption/audio route. | GraphicScene asset catalogue, sticker/shape/animated-vector pipeline. |
| Basic Rec.709 SDR Color | available | LUT plus exposure, brightness, contrast, saturation and gamma in the supported Rec.709 SDR context. | `acceptance:advanced:tools:real`, LUT identity check, and missing-LUT failure closure. | HDR, arbitrary camera color management, curves/HSL secondary. |
| Three-role Audio Mix | available | Dialogue, Music and SFX clips with gain, bounded Ducking and Master loudness. | `basic-vlog-toolkit:test` verifies encoded loudness, ducking floor/recovery and failure closure. | Arbitrary bus graphs and professional effect chains. |
| Structural Objects | unavailable | Nested, compound, and adjustment objects may be stored and validated. | `timeline-core:test`, `commit-plan:test` cover validation, cycles, and failure closure. | Rendering or tool availability; resolver must block until flattening exists. |
| Failure closure | available | Unknown effects/transitions, invalid masks, invalid remaps and invalid audio parameters reject without a successful bundle. | `timeline-render:test` and each focused tool suite. | Silent fallback or partial Timeline mutation. |

The removed `advanced-family-real-acceptance` suite is intentionally not a source of full-family capability evidence: it claimed entire professional families from FFmpeg-plan markers. It is not retained or archived, so it cannot be reused as a misleading acceptance path. Its replacement acceptance work must use the bounded names above and observable per-tool output.
