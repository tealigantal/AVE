# ADR-0055 — Explicit source-track retention (implementation in progress)

Date: 2026-11-09. Status: implementation and verification in progress; real product acceptance remains open.

## Context

The existing evidence projections require model-assessed sound events. A user can instead identify an entire source track for preservation without a sound classifier. Track existence or nonzero PCM does not establish that a particular musical or environmental event exists, and a request to keep a whole track cannot be met by retaining an arbitrary excerpt.

## Intended boundary

A versioned explicit local revision action identifies one previously authorized asset. It does not change data-sharing permissions or replace the separate environmental-sound requirement. The Host must bind the request revision, prepared material grant and original/immutable identities to a uniquely identified audio stream and complete contiguous decoded sample bounds, checked against both persisted import facts and a fresh inspection of the held immutable source. Unknown, ambiguous, missing, mismatched or unrepresentable boundaries fail closed.

The planned positive path must prove exact, ordered, gap-free source coverage on the simulated committed Timeline, with active routing and no unverified retiming or source-altering processing; then independently reconstruct the source binding and protection against the saved draft on reopen. On 2026-11-09 the user explicitly authorized replacing old implementation and protocols without migration of old projects; prior proof reconstruction is not a compatibility requirement. P5 evidence and Docker volumes remain preserved. A full-track duration inconsistent with the requested work or Timeline grid must fail explicitly, rather than silently choosing a shorter interval. Final mixed output, human audibility and sound classification are separate claims and are not established by source participation.

## Current state

The Host now constructs the source proof from its authorized material and freshly inspected held original. Planning receives only a bounded source identity and time range; the full probe remains in the Host record. The compiled Timeline is checked before commit, and saved draft reads reconstruct the material, authorization, source reference and boundary checks. The planner is instructed to split independent sound targets and cite the selected track at most once; repeated use of the same track evidence for separate requirements is rejected, and other sound requirements retain their independent evidence checks. Natural-language interpretation remains fallible: a model can merge multiple targets into one quoted requirement or omit a requirement altogether, so the track proof cannot establish that all user-requested sounds were understood or included. Controlled local-provider tests have exercised complete coverage and negative cases with encoded media; broader tamper tests and the current Docker/Chrome journey remain in progress. Manual changes that cannot prove this requirement fail explicitly. A source-track proof does not verify the nature of the sound or the subjective listening experience. These results do not complete P5.

For an explicitly selected complete source track, the Host now compiles one independent continuous audio clip from the authorized local boundary and mutes embedded audio on picture clips from that source. This permits picture reordering without sending audio to the model or mixing a duplicate of the retained track. Duration and exact time-grid conflicts, incompatible existing routes, changes to protected clip audio, and verbatim captions anchored to the muted embedded source fail explicitly. This is a conservative supported subset, not a claim that all existing routing or subtitle edits can be preserved. The independent clip still passes the normal command simulation, commit and source-proof reconstruction; explicit ambient requirements remain separate.

Manual successors can retain that requirement: the Host re-inspects the held authorized original, binds the current material and authorization to a fresh proof, validates the simulated Timeline, and reconstructs that proof and coverage when the draft is read again. The fixed independent retention track supplies the full-track proof. Additional active audio from the selected source is allowed where its actual Timeline interval does not overlap another active copy; overlapping copies are rejected with an actionable error instead of silently muting inserted video. Invalid work fails before superseding an ongoing operation. Manual edits with both full-track retention and an independently required ambient event currently fail closed because the manual receipt does not reconstruct that event evidence; source-track presence is not treated as ambient classification.
