# ADR-0062：媒体协议与文件证据迁移边界

日期：2026-11-14。状态：选定实施，尚未完成。

## 背景

Host 的素材探测、场景观察和精修仍使用 Worker v1；scene v2 已采用文件凭证，但图片与动画格式尚未完整支持。观察 v1 直接引用旧场景合同，不能仅修改任务版本或把临时文件路径写入项目。

## 决策

- scene/probe 迁移完成后仅 v2 为当前 Worker 入口，原有素材、Timeline 和用户项目不因旧分析版本被删除或就地转换。
- Host 持有不可变原件和独占 staging，验证完整文件、身份、范围、字节长度与摘要后，才将项目拥有的内容引用与新版观察通过现有事务提交；Worker 不访问项目数据库。
- 重开时重新验证证据与来源绑定。旧分析仅以版本身份识别并明确提示重建，不参与新版规划；重建须显式执行，不在打开时静默重算。已有时间线和导出的可读性须独立保留。
- 图片、动画、音频和视频均须保留既有能力及损坏输入检查。动画解码受可信配置下跨 Worker 共享资源租约与进程树回收约束；无法安全取得资源时显式失败，不能回退到无界执行。
- 按用户最新指令直接移除旧任务入口，并在同一迁移变更中完成新版 Host、Worker、存储、调用方和验证；迁移未闭包的中间状态不得视为可用。已验证的失败根因和取消、授权、事务、清理边界必须保留。

## 后果

旧观察需要用户显式重建，不能伪装成新版。该决策定义目标，不证明新版图片、资源租约、持久化或用户旅程已实现和验证。执行顺序和实际结果见 [当前计划](../plans/2026-11-12-llm-semantic-foundation.md)。

## 2026-11-14 可用性修复

用户随后要求解决不可用后停止。先前直接撤销注册而未同步 Host 造成调用链断裂，现恢复 Host 仍使用的两项 v1 注册。v2 唯一入口仍是未完成的迁移目标，不是当前事实。此次停止不代表迁移完成；后续替换必须同步实际调用方。

## 恢复迁移的切换顺序

用户重新授权完成迁移，先迁移全部调用方并验证，再撤销 v1 注册及合同。旧入口仅在本地施工期间维持现有可用性，最终状态不保留兼容入口。

## 上一节点状态（历史）

Host 的 probe、观察和精修已发送 v2；observation v2 将 scene 文件按内容摘要存入项目对象库，在现有事务内登记，与观察一并保存并在重开验证。真实 Worker/Host 定向测试通过，模型为受控夹具。上一节点暂停后用户已授权继续；旧任务注册与 Schema 尚未删除，资源压力/故障验证及长素材流式业务消费仍需完成。这不是整个迁移完成声明；执行证据与下一步以当前计划文末为准。

## 当前切换状态（2026-11-14）

旧 probe/scene 任务及旧 scene/observation 合同已在本地移除，Host 与定向测试使用新版。长素材流式消费和多 Worker 资源故障验证仍未完成；原项目及媒体不因协议切换被删除。具体验证见当前计划。
