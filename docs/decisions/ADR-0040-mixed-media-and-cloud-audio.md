# ADR-0040: mixed media and bounded cloud audio resources

Status: accepted for the user-authorized implementation; capability status belongs to programme Evidence. Date: 2026-10-02.

Existing Stage3 retains request-level authorization, Host-only state authority, exact Command/Commit and separate Preview/Master execution. Imported static images have decoded identity, orientation, geometry and alpha; their display duration is an explicit measured Timeline reservation, never a video source interval. Independent audio observations use the actual stream/sample grid and do not call scene scanning. Legacy video observation objects remain valid and immutable.

The library is fixed-version declarative data from individually verified CC0/CC BY sources. Host accepts only catalog IDs, validates bounded direct downloads or pinned compressed ZIP ranges, hashes and decoded media before import. Renderer never supplies arbitrary download instructions or sees original paths. Worker receives verified local sources. No new cloud service, global database or change to fixed Skills is required.

Library permission is a separate scope on a new request, pinned to a catalog version. Its exact selected source grant remains bound to request, authorization generation and content hash. Historical requests lacking that scope are unauthorized. Call1 chooses at most three resource IDs from at most twelve presented candidates; only selected sources are acquired and measured before Call2; Call2 cannot change the measured selection. Failed acquisition or planning leaves previous work intact.

Only sources actually selected for a project persist as ordinary immutable project assets. Unused audition content is a bounded disposable cache; cleanup never removes project originals, snapshots or historical references. This small local copy is necessary for offline reproduction and exact export, while the full library remains remote. CC BY attribution accompanies export with source, license and modification text.

Mixed geometry is rendered on the existing portrait canvas only through explicitly selected registered framing on every visual clip. Native equal-size work retains its current canvas. Planned image intervals may explain actual detected freezes; unrelated unexpected freezes remain QC blockers. Image decode honors EXIF and transparency; unsupported animation is rejected.

Alternatives rejected: downloading the whole library, third-party music API dependencies with unverified commercial terms, executable resource packs, retroactively extending old grants, and replacing the editing engine. Rollback preserves old objects and used assets; disabling the new library entry affects new requests only. No merge, deployment or release is authorized by this ADR.
