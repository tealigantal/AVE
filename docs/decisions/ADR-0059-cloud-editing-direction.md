# ADR-0059: 云端模型与可授权的云端渲染方向

日期：2026-11-11。状态：用户确定的目标方向；实现、服务选型及完整验收待后续工作。本文为稳定架构决策；既有架构文档和历史 ADR 不能同时记录这一目标变更，因此新增本记录，由 [决策索引](README.md) 导航。

## 背景与目标

用户要求自动剪辑的实际成片效果对标 Hypit、ChatCut，同时保留对同一作品的精修能力；本地部署暂缓，模型全部采用云端配置，并允许云端渲染。该决定替代此前本轮“不得云端渲染”和优先完成 2GiB 本地容器验收的取舍，不删除或改写历史记录；是否重启本地部署工作以后另行决定。

## 决策

1. 当前目标配置的视觉、创作规划、转写和声音分析均由明确选定的云端模型承担。服务、模型、版本、处理数据、权限与使用记录必须可核验；缺少配置或授权明确失败，不静默回退到本地模型或其他服务。
2. Preview 和 Master 可以由云端执行。部署位置与是否使用云端模型独立配置；本决定允许云端渲染，不宣称当前已存在可用的远端渲染服务，也不指定供应商、技术栈或收费计划。
3. Project Host 继续是项目状态和 SQLite 写入的唯一权威。远端执行者仅接受 Host 授权、版本化且绑定完整语义和目标的执行任务，不能直接写项目状态；上传或读取的素材须绑定原件/代理身份、授权范围与当前版本。Renderer 不直接访问模型 SDK、数据库或渲染命令。
4. 每个版本仍从同一 Semantic Render Manifest 派生 Preview/Master 的独立 RenderGraph 和 ExecutionPlan。Master 的选定规格和授权原素材必须可核验；不得暗降质量或丢弃效果。输出完成后由 Host 核验身份、完整性和双目标 QC，再通过现有原子发布流程登记；失败、取消、权限变化、重复任务和结果不确定都不能报告成功。
5. 云端传输和费用以明确用户授权为前提，显示处理位置、提供者、涉及数据与可获得的费用信息；凭据不进入浏览器、镜像或日志。应设计取消、重试、幂等、已发送但结果未知的账目、数据保留/删除、网络中断与恢复；具体机制须在实现前的工作包和协议中确定。
6. 自动剪辑与用户精修共用版本化 Timeline、CommandEditIR/CommitPlan 和可撤销版本；任何云端结果不得绕过上述权威链。对标质量通过同素材同任务的真实作品测试，包括叙事、选片、节奏、字幕、音画、包装、可精修性及导出/重开，不把供应商宣传或单一合成测试作为等效证明。

## 未决与迁移边界

云端主机/渲染供应商、密钥管理、上传模式、成本上限、数据存放地域、预览延迟、清理期限和失败恢复协议尚未选定；不得据此擅自外传素材、增加授权或宣称云端渲染可用。历史成功作品字节和记录保留，旧草稿重新执行须重新验证素材、权限及目标。现有本地镜像和容器状态不因本决策被修改。具体交付范围、合同、验收与回滚属于后续实施工作包，不在本次文档研究中自动推进。
