# Competitor Analysis

Competitor research compares user journeys, collaboration model, explanation,
revision locality, evidence handling, timeline escape hatch, export/QC and
privacy—not merely feature counts. Each comparison records checked date,
version, public evidence, uncertainty and decision impact.

The result is a gap or opportunity hypothesis for AVE. It must not copy
proprietary behavior, assume undocumented implementation, or override AVE's
Project Host and fail-closed boundaries.
