# Render Backend Comparison

FFmpeg is the existing repository execution boundary, not a blanket proof of v1 effects. MLT, libopenshot and GStreamer Editing Services are unverified candidates. Compare only through the Backend Adapter contract: graph coverage, parameter semantics, alpha/color, determinism, cache behavior, structured errors, licensing and Preview/Master parity. A candidate is never made authoritative; Project Host, `CommandEditIR`, the Semantic Render Manifest, and target-specific RenderGraphs remain authoritative.
