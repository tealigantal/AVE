# AVE free audio resource pack

This directory contains fixed-version data and curation receipts, never a downloadable full audio library. The catalog pins 40 distinct OpenGameArt music tracks and 80 distinct Kenney sounds by SHA256. Current items are CC0; the contract also permits individually verified CC BY 3.0/4.0 with required attribution. Each original source, author, license notice identity, download endpoint, measured display length, channels, sample rate and decoded waveform is recorded in the catalog. Use tags are editorial suggestions from source genre/tags, not human listening acceptance. Unknown BPM, vocal status and loop boundaries remain null or empty.

Host only downloads a selected original-site attachment or one exact ZIP member range, validates length and SHA256, probes actual contiguous audio, then uses existing immutable project material preparation. Audition is bounded to 15 seconds and a disposable 64 MiB cache. Used sources remain in project originals and historical versions after cache cleanup, including offline reopen/render. Renderer receives bounded Host data, never an arbitrary URL download command.

Run `pnpm audio-pack:check` for schema, identity, coverage, license and bound full-PTS/actual-Worker receipt checks. `pnpm audio-pack:check -- --network --report=<outside-repository-path>` repeats actual original-site downloads, license notices, full decode and Worker audition; it requires FFmpeg and the configured AVE Python runtime. Failures are explicit and the report preserves completed items. Curation work downloads stay outside the repository. The two small CC0 downloader test fixtures are separately documented under tests/fixtures/stage3/audio-library.
