# P4 工作台交互蓝图

`index.html`、`demo.js`、`demo.css` 是正式P4的唯一UI与交互设计依据；固定文件摘要在 [DOC-007](../../docs/plans/2026-10-03-reliable-workbench-real-acceptance.md)。产品逐操作范围只维护在 [P4工作包](../../docs/program/creative-assistant-stage3/work-packages/WP-S3-RELIABLE-UX-001.md)，稳定行为见 [Workspace Design](../../docs/ux/WORKSPACE_DESIGN.md)。先完成真实功能，再复现界面。

直接打开 `index.html` 可查看独立演示，不需要安装依赖。若工具不支持file URL，使用获准的本地静态服务；不为查看demo修改产品服务或原始数据。

## 页面与操作

| 页面 | 蓝图内容 |
| --- | --- |
| 创作 | 素材选择、真实产品应有的播放器位置、整部作品/当前镜头范围及共享对话 |
| 素材 | 分类搜索、网格/紧凑网格/列表、缩略图尺寸、独立面板宽度、音乐/音效目录入口；此页不直接写Timeline |
| 精修轨道 | 资源栏、中央预览、属性栏与多轨时间线；独立尺寸/折叠、可视标尺、帧级定位/吸附、拖放/修边/分割/删除/撤销重做 |
| 版本历史 | 点击观看与明确采用分开；比较和版本身份 |
| 问题与恢复 | 短提示与持久问题分开，根因及下一步可查 |
| 作品管理 | 作品卡、打开和移入回收站 |
| 回收站 | 逐项/全部恢复、逐项/全部永久删除、确认与取消 |
| 帮助 | 对应实际播放、选择、分割、删除、撤销/重做、滚轮与吸附手势 |
| 导出 | 版本、质量/QC、保存位置、进度和结果 |

全局会话/普通输入节点固定，创作与精修共享；气泡可拖动并保存UI位置。批注有独立正文窗，可添加/编辑/移除/清空待发列表，再与整体要求一次发送。演示回复后清活动标记，历史保留锚点。正式产品必须实现真实处理状态，不能用本演示回复表示问题已解决。

## 时间线操作对照

- 主视频/图片：完整插入并顺延、前后重排、选择、左右修边、显式分割、删除、复制到PiP及跨轨。
- PiP：拖动中的临时轨、有效落下才建轨、同轨移动/拒绝重叠、修边/分割/删除及回主轨。预览随播放头叠画；demo没有画面内变换手柄。
- 音频/音效、字幕/文字：匹配轨道拖入、临时建轨、选择、移动、修边、分割、删除。字幕预览Enter/失焦提交、Escape取消；字体/字号/颜色/粗体。
- 可选轨：手动新建、删除连内容、末项移走/删除后的清理、撤销恢复；主视频不可删，PiP紧邻主视频。
- 效果：灰度/黑白/模糊选择、应用、替换、无效果/删除及撤销；同目标不静默叠加。生产须依据真实注册集合，不照搬模拟实现的偏差。
- 转场：相邻主视频剪辑点交叉叠化、再次放置替换、标记选择、Delete删除、撤销恢复，不建独立转场轨。边缘淡化卡不是可拖入的剪辑点转场。
- 时间轴：无示例片长上限，内容外空白能定位/落片；标尺只画可视区域，滚轮锚定缩放、Shift竖滚、Alt横移；吸附首尾边、排除当前片段自身边界，8px阈值和吸附开关。一次松手一次操作，取消不留状态。

## 演示边界

全部项目、素材、缩略图、回复、问题和导出是模拟数据。demo不读真实原片、不连接Project Host/模型/云、不改真实Timeline、不删真实项目、不生成真实成片。localStorage保存的演示消息/UI偏好不是项目权威，CSS效果不是Preview/Master渲染。

顶部状态演示器、固定库存和模拟业务不进入生产。未连接图片/视频/字体贴纸商店、智能包装、模板、数字人、联网学习/采集和未注册特效只显示明确空态/不可用原因；它们不扩大本P4范围。产品操作清单中的功能不能因此被禁用占位替代。

本说明不保存“后端尚无批注/回收站”等易过期状态。当前真实能力、缺口、验证由工作包、DOC-007和generated current给出；历史演示操作不证明产品完成。人工反馈可选，完成由真实自动验证及可追溯结果判断。
